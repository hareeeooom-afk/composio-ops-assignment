Strategic Patterns & Macro Findings

1. Auth Infrastructure Split

B2B SaaS & Ads (Salesforce, Meta, HubSpot) strictly require OAuth2 with granular scopes. Conversely, Developer Platforms, Scraping, & AI microservices (Supabase, Firecrawl, Reducto) rely on simple API Keys / Bearer Tokens with zero onboarding friction.

2. The "Shadow" Gating Factor

15% of apps appear public but hide behind paid tiers or manual review (e.g. Squarespace locks APIs behind Advanced Commerce, Google Ads requires Developer Token approval, Amazon SP-API demands Seller approval).

3. Composio Toolkit Prioritization

62 immediate wins can be auto-generated via OpenAPI schemas. 12 apps (PitchBook, DealCloud, Gladly) require enterprise partnership motions, and CLI tools (Sherlock, Mermaid) need containerized exec wrappers.

How the Agent Researched the 100 Apps

  1. Stage 1: Async Documentation Discovery

    Queries Composio search & developer portals to locate official API reference docs, OpenAPI specs, and auth guides.

  2. Stage 2: Schema Extraction & Classification

    Extracts auth types (OAuth2, Key, Basic), sandbox availability, pricing gates, and MCP existence into a Pydantic schema.

  3. Stage 3: Where Human Intervention Was Required

    Differentiating between consumer app login vs. developer API portal access (e.g. Otter AI, Fanbasis) where agents falsely assumed self-serve API access.
